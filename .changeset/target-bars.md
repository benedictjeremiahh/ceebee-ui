`TargetBars` — actual against target per category, a bullet chart. Every row shares one scale that always contains zero, so a small margin never looks large and a loss draws left of the line; the target is a mark on the same track. Both figures are written as text and the bars are `aria-hidden`; a `null` figure reads as unknown rather than zero. Server-safe, plain DOM, with forced-colors and reduced-motion renderings. `better="lower"` serves costs and delays.
