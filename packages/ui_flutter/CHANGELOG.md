# Changelog

## 0.1.0-dev.3

- The moodboard Skin now carries its own high-contrast edges, in its own warmth,
  instead of falling back to the base's neutral ones. The values are the ones a
  product had already tuned and shipped locally.

## 0.1.0-dev.2

- Added the moodboard Skin, so the warm taped-paper palette is available to
  Flutter consumers rather than living only in this repository.
- Regenerated the Skin and Structure Tokens from the CSS sources.
- Corrected the timeline Skeleton.

## 0.1.0-dev.1

- Added generated cross-platform Skin, Structure, Surface, motion, and data
  visualization Tokens.
- Added the Material 3 Theme bridge and Ceebee Surface variants.
- Added compact Donut, Sparkline, and BarMini data visualizations with static
  Skeleton companions.
- Added reduced-motion-aware Reveal and Stagger primitives.
- Added the mobile-friendly Checklist composition and Skeleton.
- Added native form, selection, navigation, overlay, feedback, data-display,
  date/time, pagination, rating, colour-picker, and upload components selected
  for mobile interaction contracts.
- Added geometry-matched Skeleton companions for every composition.
- Added responsive gallery, semantic and interaction coverage, plus
  deterministic compact/wide light/dark golden baselines.
