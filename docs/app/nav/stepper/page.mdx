# Steps <span className="docs__label">Composition</span>

Position in an ordered sequence — the thing Tabs must not be used for, because tabs let a person
skip straight to step three.

## Usage

<StepperDemo />

## What it announces

Completed and current steps carry a visually hidden "(completed)" and "(current step)". Without
them the state is a colour and a tick, and neither reaches a screen reader.

<Guidance
  do="Keep it to five steps or fewer; past that a progress bar with a count reads better."
  dont="Make the markers clickable to jump ahead — if steps can be visited in any order, they were not steps."
/>
