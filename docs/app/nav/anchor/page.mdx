# Anchor <span className="docs__label">Composition</span>

In-page section navigation rendered as native hash links. `Anchor` is server-safe: the consuming
application decides which section is active and injects `activeId` when it has that information.

## Usage

<Demo
  layout="block"
  code={`<Anchor
  items={[
    { id: 'overview', label: 'Overview', href: '#overview' },
    { id: 'api', label: 'API', href: '#api' },
  ]}
  activeId="overview"
/>`}
>
  <Anchor
    items={[
      { id: 'anchor-usage', label: 'Usage', href: '#usage' },
      { id: 'anchor-props', label: 'Props', href: '#props' },
      { id: 'anchor-tokens', label: 'Tokens', href: '#tokens' },
    ]}
    activeId="anchor-usage"
    aria-label="Anchor example navigation"
  />
</Demo>

## Nested sections

An item may carry `children` for subsections. `activeId` adds `aria-current="location"` to the
matching link at any depth.

<Demo
  layout="block"
  code={`<Anchor
  items={[
    {
      id: 'api',
      label: 'API',
      href: '#api',
      children: [
        { id: 'api-props', label: 'Props', href: '#api-props' },
        { id: 'api-events', label: 'Events', href: '#api-events' },
      ],
    },

  activeId="api-events"
/>`}
>

## Anatomy

The root is a `<nav>` landmark containing native nested `<ul>` lists and `<a href="#section-id">`
links. An item may contain `children` for subsections. `activeId` adds `aria-current="location"` to
the matching link at any depth.

## Boundary

Use Anchor for navigation within the current page. It does not observe scrolling, mutate the URL,
intercept clicks, own focus, dismiss, portal, or handle gestures. Inject `activeId` from an app-owned
scroll observer or router when needed. Breadcrumb describes location hierarchy; Tabs selects a
panel and has a different keyboard contract.

## Keyboard

Native link behaviour only: Tab moves through the links in document order and Enter follows the
focused one. There is no roving focus, typeahead, or arrow-key model to learn.

## Tokens

`--cb-space-*`, `--cb-text-*`, `--cb-font-sans`, `--cb-weight-medium`, `--cb-radius-sm`,
`--cb-border-width`, `--cb-border`, `--cb-fg`, `--cb-fg-muted`, `--cb-focus-*`, `--cb-tone-*`,
`--cb-duration-fast`, and `--cb-ease-standard`.

<Guidance
  do="Keep hrefs as real fragment links and derive activeId in the consuming app."
  dont="Use Anchor as a scroll spy, a tab list, or a replacement for Breadcrumb."
/>
