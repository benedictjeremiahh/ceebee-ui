# Tabs <span className="docs__label">Composition</span>

Panels that share a place on the page. Roving focus, panel association, and the moving indicator
come from Base UI; the two variants are ours.

## Usage

<TabsDemo />

## Underline or pill

`underline` is for page-level sections — it reads as navigation. `pill` is for switching a view of
the same data, like a date range, where the choice is a filter rather than a place.

<Guidance
  do="Keep tab labels to one or two words; the indicator animates to their width and long labels make it lurch."
  dont="Use Tabs for a sequence with an order — that is a Stepper, and tabs let a person skip step two."
/>

## Keyboard

| Key | Behaviour |
| --- | --- |
| `←` / `→` | Moves between tabs |
| `Home` / `End` | First and last tab |
| `Tab` | Leaves the tab list and enters the panel |
