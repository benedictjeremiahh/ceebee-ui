## The last crumb is not a link

It is text carrying `aria-current="page"`. A link to the page you are already on is a dead end —
it looks actionable, it consumes a tab stop, and it does nothing.

Longer trails collapse in the middle rather than wrapping onto a second line: the first crumb and
the last two are what people actually use.

<Guidance
  do="Mirror the real hierarchy, so the trail is a way up and not a history of clicks."
