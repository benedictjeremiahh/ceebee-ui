# Sidebar · TopBar <span className="docs__label">Composition</span>

The app shell: navigation down the side, context across the top. Both are slot-driven, because
every product disagrees about what belongs in its chrome.

## Usage

<ShellDemo />

## Submenus

An item with `items` is a disclosure rather than a destination: it expands in place, its children
indent against a rail, and a child being active keeps the parent open and marked.

## Collapsed is still navigable

Collapsing hides the labels visually and keeps them in the accessible name, so a screen reader
still reads "Invoices" where a sighted user sees only an icon. Hovering or focusing a rail item
opens a flyout carrying that label — and, for a parent, its whole submenu — so a collapsed rail
stays readable instead of becoming a column of guesses.
