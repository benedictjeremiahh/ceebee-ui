# Menu <span className="docs__label">Composition</span>

Persistent navigation in document flow. It renders native links for destinations and disclosure
buttons for nested branches. `Menu` is client-bound because it can own controlled or uncontrolled
selection and branch-expansion state.

## Usage

`selectedPath` adds `aria-current="page"` to the matching entry. It is the encoded path of keys
from the root (for example, `projects/active`), so equal local keys in different branches never
collide. The consuming app supplies that path from its router; `defaultSelectedPath` leaves the
menu uncontrolled.

  code={`<Menu
  selectedPath="projects/active"
  defaultOpenKeys={['projects']}
  items={[

      key: 'projects',
      label: 'Projects',
      ariaLabel: 'Project sections',

  ]}

## Branches

Branches expand independently, so more than one can be open at a time. A branch label may be any
React node, which is why its disclosure control takes an explicit `ariaLabel`.

<Demo

>
  <Menu
    defaultOpenKeys={['projects', 'settings']}

## Interaction boundary

- **Role:** a navigation landmark containing a list of destinations and optional nested branches.
- **Keyboard and focus:** every link and disclosure button remains in native Tab order. Enter follows
  a link or toggles its focused branch button. There is no roving focus or typeahead.
- **State:** `selectedPath` / `defaultSelectedPath` control the current destination; `openKeys` /
  `defaultOpenKeys` control independently expanded branches.
- **Dismissal:** none. The menu stays in the page layout; a branch only changes through its own
  disclosure button or controlled state.
- **Positioning:** no anchor, portal, or viewport collision logic.
- **Gestures:** native link and button activation only.

`Dropdown` is intentionally separate: it is an anchored, dismissible action menu with Base UI
roving focus and typeahead. Use `Menu` when destinations should remain visible in a navigation
region.

## Skeleton

`Menu.Skeleton` accepts `items`, `size`, `tone`, and `aria-label`. It preserves the navigation
landmark and row geometry while destinations are loading.

## Keyboard

| Key | Result |
| --- | --- |
| `Tab` / `Shift+Tab` | Moves through visible links and disclosure buttons in document order. |
| `Enter` | Follows the focused native link or expands/collapses the focused branch. |
