# DropdownMenu <span className="docs__label">Composition</span>

Actions on a thing — the row-actions menu, the account menu. Typeahead, roving focus, and
dismissal are Base UI's; the surface, the separator rhythm, and the danger tone are ours.

## Keyboard

| Key | Behaviour |
| --- | --- |
| `Enter` / `Space` / `↓` | Opens |
| `↑` / `↓` | Moves the highlight, skipping disabled items |
| Typing | Jumps to the first matching item |
| `Esc` | Closes and returns focus to the trigger |
