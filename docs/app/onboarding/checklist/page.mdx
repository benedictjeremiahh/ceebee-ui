# Checklist <span className="docs__label">Composition</span>

Getting-started tasks with progress — the quieter half of onboarding, next to the Tour.

## Usage

<ChecklistDemo />

## It does not know what is done

Which tasks are complete is passed in, exactly as a Tour's memory is. The library holds no account
state, because a checklist that decides for itself what "done" means is one that disagrees with
your backend the first time someone completes a step on another device.

<Guidance
  do="Give completeSlot something worth reaching — the checklist should be able to disappear."
  dont="Leave a finished checklist on the page forever; it turns from encouragement into clutter."
/>
