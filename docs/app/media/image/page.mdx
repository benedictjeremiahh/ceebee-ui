# Image <span className="docs__label">Composition</span>

`Image` reserves layout space and reveals an image after it loads. `Image.PreviewGroup` is the
separate, client-side viewing contract for fullscreen preview, grouped navigation, and zoom. Keeping
them separate means a plain image never silently becomes a button or acquires dialog semantics.

## Usage

<ImageDemo />

<ImagePreviewDemo />

```tsx
import { Image } from "@ceebee/ui/client";

const photos = [
  {
    id: "front",
    src: project.frontThumbnail,
    previewSrc: project.frontOriginal,
    alt: "Front elevation",
    caption: "Front elevation after the second site visit",
    aspectRatio: 4 / 3,
  },
  {
    id: "side",
    src: project.sideThumbnail,
    previewSrc: project.sideOriginal,
    alt: "Side elevation",
    aspectRatio: 4 / 3,
  },
];

<Image.PreviewGroup items={photos} label="Site visit photos" />;
```

The source adapter remains outside the library: pass CDN transformations, signed URLs, or imported
assets through `src` and `previewSrc`. Image does not fetch metadata, manufacture URLs, or assume a
framework image service.

## Anatomy

The base component contains a reserved frame, optional blur placeholder, and native `<img>`. A
preview group adds named thumbnail buttons and a portalled Base UI dialog containing:

1. Position announcement and zoom/close toolbar.
2. Previous and next controls around the full-size image.
3. Optional caption for the selected item.

Base UI owns focus trapping, Escape dismissal, scroll locking, and restoration to the thumbnail
that opened the preview. Selecting another item resets zoom so an old transform never leaks into a
new image.

<Guidance
  do="Give every meaningful image useful alt text and pass a larger previewSrc when thumbnails are optimized."
  dont="Put click handlers on a plain Image or use a decorative image as the only accessible name for a preview trigger."
/>

## Skeleton

`Image.Skeleton` accepts `aspectRatio`, `radius`, and `className`. It uses the same frame geometry as
`Image`, is hidden from assistive technology, and drops its sweep under reduced motion.
`Image.PreviewGroup.Skeleton` repeats that geometry in the same responsive thumbnail grid.

```tsx
<Image.Skeleton aspectRatio={4 / 3} radius="lg" />
<Image.PreviewGroup.Skeleton items={3} aspectRatio={4 / 3} />
```

## Keyboard map

| Key                        | Result                                                            |
| -------------------------- | ----------------------------------------------------------------- |
| `Enter` / `Space`          | Opens the focused thumbnail.                                      |
| `Escape`                   | Closes the preview and restores focus to its trigger.             |
| `ArrowLeft` / `ArrowRight` | Selects the previous or next image when available.                |
| `Home` / `End`             | Selects the first or last image.                                  |
| `+` / `-`                  | Zooms in or out between 1× and 3×.                                |
| `0`                        | Resets zoom to 1×.                                                |
| `Tab` / `Shift+Tab`        | Moves through controls while focus remains trapped in the dialog. |

Double-clicking at 1× sets 2×; double-clicking any zoomed state resets to 1×. Navigation, closing, or
selecting another thumbnail always resets the scale.

## Tokens

Image and preview read `--cb-bg-subtle`, `--cb-surface-raised`, `--cb-fg`, `--cb-scrim-strong`, `--cb-fg-on-brand`,
`--cb-tone-brand`, the semantic border/focus tokens, `--cb-space-*`, `--cb-radius-*`,
`--cb-control-height-md`, `--cb-duration-*`, `--cb-ease-*`, `--cb-z-modal-backdrop`, and
`--cb-z-modal`. Consumer-provided `background` must be a token expression.
