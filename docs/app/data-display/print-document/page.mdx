# PrintDocument <span className="docs__label">Atom</span>

A passive boundary that selects caller-rendered content for native browser printing. It adds no
print button, keyboard shortcut, dismissal, or focus behavior; the browser owns the print dialog.

<PrintDocumentDemo />

## Print scope

When several active boundaries are present, the last one in document order supplies the snapshot.
The snapshot contains already-rendered static HTML and image markup. The live React content stays
mounted, and the helper restores the original theme attributes when printing ends.

Keep styles independent of ancestors outside the boundary. Selectors that rely on those ancestors
may no longer match the snapshot. Canvas output is not copied, and ID selectors inside embedded
`<style>` elements are not rewritten. The component does not fetch data or remount content, and it
does not promise interactive form state in the printed copy.

`colorMode="light"` temporarily selects the light theme for printing; `colorMode="current"` keeps
the current theme. Both modes restore the original theme attributes after printing.

## Keyboard

PrintDocument adds no keyboard handling, controls, or dismissal, and it does not move focus. Its
children retain their own keyboard behavior. Browser-native print commands and the print dialog
remain browser-owned.

## Tokens

`--cb-surface` supplies the paper background while the boundary is active. Document typography, spacing,
and page geometry remain caller-owned.
