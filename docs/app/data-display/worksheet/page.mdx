# Worksheet <span className="docs__label">Atom</span>

An editable, fixed-schema grid with keyboard navigation, frozen columns and external rectangular
paste. The pinned MIT `react-data-grid` 7.0.0-beta.57 runtime owns selection, focus, virtualization,
ARIA grid semantics and cell editing. Ceebee owns token styling and atomic TSV paste mapping.

## Usage

<WorksheetDemo />

Define columns with stable keys and editors, then pass `rows` and `onChange`. A column additionally
needs a pure `write(row, clipboardText)` function to accept range paste. Keep calculated values and
reference selections protected by omitting `write`; use `editable(row)` for per-row restrictions.
Use `pasteable` when a cell remains directly editable but should reject external range paste, such
as a section heading; it accepts a boolean or row predicate and defaults to true. The caller owns
parsing, validation, persistence and localized failure messages.

Set `headerGroup` on adjacent columns to render one shared heading above their leaf headers. Its
`key` joins only consecutive columns with the same key; an ungrouped column or a different key
starts a new run. The `name` supplies the group heading. The wrapper exposes
`--cb-worksheet-header-rows` as `1` or `2` so a containing region can account for the header height.
Keyboard selection also requests the runtime’s scroll-to-cell geometry so custom focusable cell
content stays visible when navigating across a wide worksheet.

Set `rowHeight="auto"` when rendered cell content needs variable row heights. Auto mode measures
visible cells and their direct child geometry, caches heights by row object and stable column key,
then lets the grid keep ownership of virtual row positions, selection and editing. A measured
offscreen column continues to contribute to its row height; replacing a row object invalidates its
cached measurements. The normal token row height remains the minimum. Auto mode sets
cell content to normal wrapping and top alignment, but custom cell wrappers still need wrapping
styles where their own CSS uses ellipsis or `white-space: nowrap`. Unmeasured virtual rows start at
the minimum height; as they enter view, the native scrollbar thumb can update when their measured
heights change. The wrapper exposes `--cb-worksheet-content-height`, including all current row
heights, header rows and a spacing Token for the native scrollbar; a containing region can cap its
block size against the viewport using that value.

## Keyboard and paste

Arrow keys navigate cells; Enter or typing starts an editable cell, Tab commits and moves, and
Escape cancels an active editor. The runtime owns that keyboard map. Native single-cell text paste
stays native. With `editOnClick`, clipboard tabs/newlines also map a range from an active cell editor.
Paste on a selected grid cell maps a rectangular plain-text TSV range, including quoted
tabs/newlines, up to 10,000 cells. A protected destination rejects the whole range. Paste beyond
existing rows requires `createRow`. Ragged or malformed clipboard text is refused.

This is a fixed-schema worksheet, without arbitrary formula execution, file import, merged-cell
editing, range-copy UI or drag-fill. The dependency is a pinned beta, so upgrading it requires
keyboard, clipboard and rendered acceptance rather than assuming upstream main's API is identical.
