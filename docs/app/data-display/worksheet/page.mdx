# Worksheet <span className="docs__label">Atom</span>

An editable, fixed-schema grid with keyboard navigation, frozen columns and external rectangular
paste. The pinned MIT `react-data-grid` 7.0.0-beta.57 runtime owns selection, focus, virtualization,
ARIA grid semantics and cell editing. Ceebee owns token styling and atomic TSV paste mapping.

## Usage

<WorksheetDemo />

Define columns with stable keys and editors, then pass `rows` and `onChange`. A column additionally
needs a pure `write(row, clipboardText)` function to accept range paste. Keep calculated values and
reference selections protected by omitting `write`; use `editable(row)` for per-row restrictions.
Use `pasteable` when a cell remains directly editable but should reject external range paste, such
as a section heading; it accepts a boolean or row predicate and defaults to true. The caller owns
parsing, validation, persistence and localized failure messages.

<Guidance do="Use pasteable(row) for paste-only restrictions; validate values before persistence."
  dont="Turn saved prices or calculated cells into writable text just to accept a wider clipboard range." />

## Keyboard and paste

Arrow keys navigate cells; Enter or typing starts an editable cell, Tab commits and moves, and
Escape cancels an active editor. The runtime owns that keyboard map. Native text-input paste stays
native. Paste on a selected grid cell maps a rectangular plain-text TSV range, including quoted
tabs/newlines, up to 10,000 cells. A protected destination rejects the whole range. Paste beyond
existing rows requires `createRow`. Ragged or malformed clipboard text is refused.

This is a fixed-schema worksheet, without arbitrary formula execution, file import, merged-cell
editing, range-copy UI or drag-fill. The dependency is a pinned beta, so upgrading it requires
keyboard, clipboard and rendered acceptance rather than assuming upstream main's API is identical.
