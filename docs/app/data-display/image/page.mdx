# Image

Preview-able image.

## When to use

- When you need to display pictures.
- Display when loading a large image or fault tolerant handling when loading fail.

## Examples

<ImageShowcase />

## API

`Image` and `Image.PreviewGroup` are exported from `@ceebee/ui/client`.

Preview control names use `LabelsProvider` keys, including `imagePrevious`, `imageNext`, and the
image transform labels. Ant Design continues to own preview navigation, zoom, focus, keyboard, and
dismissal behavior.
