# DiagramEditor <span className="docs__label">Composition</span>

Draws and edits a diagram of nodes joined by arrows. The caller owns the nodes and edges; every change is a
request the caller applies, or does not.

## Interaction contract

The editor runs on the React Flow runtime (`@xyflow/react`) and keeps its interaction model rather than
re-implementing one. Nodes and edges are focusable; `Enter` or `Space` selects the focused one, arrow keys
move selected nodes one grid cell, and `Delete` or `Backspace` asks to remove the selection. With a pointer,
drag a node to move it, drag from one handle to another to connect — or click one handle and then another,
which works on touch — and drag the background to pan.

Nothing is applied by the component. A move is reported in whole cells when the drag ends or the key is
pressed, and snaps back unless the caller updates `nodes`; a connection, a removal (a node brings the edges
touching it) and a rename are requests too. The component does not know what a valid diagram is.

React Flow has no keyboard way to connect, so this component adds one: `C` on a focused node begins a
connection and `C` on another node commits it, announced through a status message; `C` on the starting
node or `Escape` cancels. `F2` asks to rename the focused node or edge — the caller renders the input.

A selected node says what it is through `renderInspector`: the editor hands it the selection described in
a person's terms — the node with where it leads and what leads to it, or an edge with both ends — and draws
the consumer's panel beside the canvas, or below it on a narrow screen. Put the actions there as real
buttons (rename, connect, remove); the shortcuts stay as accelerators, and on a phone the panel is the only
way to act. The diagram opens fitted, but never below a readable zoom; labels wrap to two lines with the full
text as a tooltip; `legendLabels` names the node shapes in use.

## Skeleton

`DiagramEditor.Skeleton` is the same loading state as `Diagram.Skeleton`.

## Keyboard

| Key | Result |
| --- | --- |
| `Tab` | Moves between nodes, edges and the controls |
| `Enter` / `Space` | Selects the focused node or edge |
| Arrow keys | Request moving the selected nodes one grid cell |
| `Delete` / `Backspace` | Request removing the selection, with the edges touching removed nodes |
| `C` | Begin connecting from the focused node; while connecting, connect to it |
| `Escape` | Cancel connecting; clear the selection |
| `F2` | Request renaming the focused node or edge |

## Tokens

`--cb-space-5` (one grid cell), `--cb-canvas-block-size`, `--cb-surface`, `--cb-border*`, `--cb-tone-*`,
`--cb-fg*`, `--cb-focus-*`, `--cb-radius-*` and `--cb-text-*`.
