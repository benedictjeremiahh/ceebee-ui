# Grid

A 24-column responsive layout system.

## When to use

Use Row and Col when content requires responsive spans, offsets, ordering, gutters, or breakpoint-aware layout.

## Also available

Ceebee's server-safe `Grid` and `Container` remain at `@ceebee/ui`; use `@ceebee/ui/client` for the full 24-column contract.
