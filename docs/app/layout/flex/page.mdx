# Flex

A semantic alternative to CSS flex layout, with a responsive and token-aware API.

## When to use

Use Flex for one-dimensional alignment, distribution, wrapping, and consistent gaps.

## API

`Flex` and `FlexProps` are exported from `@ceebee/ui/client`.

## Also available

Ceebee's token-constrained server-safe `Flex` remains at `@ceebee/ui`; use `@ceebee/ui/client` for this complete API.
