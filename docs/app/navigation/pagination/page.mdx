# Pagination

Separates long lists into pages.

## When to use

Use Pagination when loading or displaying every record at once would be inefficient or difficult to scan.

<PaginationShowcase />

## API

`Pagination` and `PaginationProps` are exported from `@ceebee/ui/client`.

<ApiReference component="Pagination" />

Enter or Space on a previous or next arrow advances one page. The inner native button does not also trigger the parent list item's keyboard handler, so one key press produces one page change. Pointer behavior, disabled state, and the outer page-item keyboard targets stay with Ant Design.
