# Anchor

Hyperlinks to scroll on one page.

## When to use

For displaying anchor hyperlinks on page and jumping between them.

> Notes for developers
>
> After version `4.24.0`, Anchor was rewritten as a function component. Methods that obtain a ref and call internal instance methods are invalid.
