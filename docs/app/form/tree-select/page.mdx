# TreeSelect <span className="docs__label">Composition</span>

A collapsed form control that chooses one injected Tree path. It is not `Tree`: Tree remains an
inline hierarchical display. It is not Cascader: TreeSelect exposes one anchored Tree traversal,
not a sequence of column pickers.

## Usage

<Demo
  layout="block"
  code={`<TreeSelect label="Owner" defaultValue="team/design" nodes={nodes} />`}
>
  <TreeSelect
    label="Owner"
    defaultValue="team/design"
    nodes={[
      {
        key: 'team',
        label: 'Teams',
        children: [
          { key: 'design', label: 'Design' },
          { key: 'platform', label: 'Platform' },
          { key: 'contractors', label: 'Contractors', disabled: true },
        ],
      },
      {
        key: 'people',
        label: 'People',
        children: [
          { key: 'ada', label: 'Ada Putri' },
          { key: 'rio', label: 'Rio Hakim' },
        ],
      },
    ]}
  />
</Demo>

## Interaction boundary

- **Role:** one labelled button opens an anchored `tree`.
- **Keyboard and focus:** Base UI owns trigger focus, outside dismissal, and focus return. Tree owns
  roving hierarchy focus; selecting an enabled node closes the popup and returns to the trigger.
- **State:** `value` / `defaultValue` own one recursive selected path; `open` / `defaultOpen` own popup state.
- **Dismissal and positioning:** Base UI Popover owns Escape/outside dismissal and anchored placement.
- **Data:** `nodes` is synchronous app-injected hierarchy; TreeSelect never fetches data.

## Empty and placeholder

`defaultValue={null}` starts with nothing chosen; `placeholder` is what the trigger says until
something is.

<Demo
  layout="block"
  code={`<TreeSelect label="Owner" defaultValue={null} placeholder="Choose an owner" nodes={nodes} />`}
>
  <TreeSelect
    label="Owner"

## Keyboard

| Key | Behavior |
|---|---|
| `Enter` / `Space` | Opens the anchored Tree from the trigger, or selects the focused node. |
| `Arrow Up` / `Arrow Down` | Moves Tree focus between visible nodes. |
| `Arrow Right` / `Arrow Left` | Expands or collapses a branch, then moves between parent and child. |
| `Home` / `End` | Moves to the first or last visible node. |
| `Escape` | Dismisses the popup and returns focus to the trigger. |

<Guidance do="Use TreeSelect when one form value comes from a hierarchy whose shape benefits from Tree traversal." dont="Use it for multi-select, async search, or step-by-step column navigation." />
