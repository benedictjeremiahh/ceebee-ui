# Transfer <span className="docs__label">Composition</span>

`Transfer` assigns an application-supplied collection between exactly two persistent lists. It is
not a sortable board, drag-and-drop surface, popup, or menu.

## Usage

Tick items in either list, then press a move action. Selection is transient — it clears for the
records that actually moved.

<Demo
  layout="block"
  code={`<Transfer
  items={[
    { key: 'design', label: 'Design' },
    { key: 'engineering', label: 'Engineering' },
    { key: 'finance', label: 'Finance', disabled: true },
  ]}
  defaultTargetKeys={['engineering']}
  sourceTitle="Available teams"
  targetTitle="Assigned teams"
  onTargetKeysChange={(keys) => save(keys)}
/>`}
>
  <Transfer
    items={[
      { key: 'design', label: 'Design', description: '6 people' },
      { key: 'engineering', label: 'Engineering', description: '18 people' },
      { key: 'support', label: 'Support', description: '4 people' },
      { key: 'finance', label: 'Finance', description: 'Managed elsewhere', disabled: true },
      { key: 'legal', label: 'Legal', description: '2 people' },
    ]}
    defaultTargetKeys={['engineering']}
    sourceTitle="Available teams"
    targetTitle="Assigned teams"
    aria-label="Assign teams"
  />
</Demo>

`key` is a stable unique item identity. `targetKeys` is the controlled assignment value; when it is
supplied, `onTargetKeysChange` reports an intent and the caller updates the list. Selection checks
are intentionally internal and clear only for items that successfully move.

<Guidance
  do="Use Transfer when people need to assign a visible set of records between two destinations."
  dont="Use Transfer for sorting, freeform drag-and-drop, or a contextual action list."
/>

## Interaction boundary

- **Role:** two labelled checkbox-list groups with explicit move actions.
- **Keyboard and focus:** native Tab, Space, and checkbox behaviour; move actions are native buttons.
- **State:** `targetKeys` / `defaultTargetKeys` own assignment. Checkbox selection is local transient
  state and is intentionally not exposed or persisted.
- **Dismissal and positioning:** none; both lists remain in document flow.
- **Gestures:** no drag, drop, or reordering.

## Keyboard

| Key | Result |
| --- | --- |
| `Tab` / `Shift+Tab` | Moves through visible native checkboxes and move buttons. |
| `Space` | Selects or clears the focused enabled checkbox. |
| `Enter` / `Space` on a move action | Moves enabled selected records in that direction. |
