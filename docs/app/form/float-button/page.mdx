# FloatButton <span className="docs__label">Atom</span>

`FloatButton` is one persistent native action fixed to a viewport corner. It is an action, not a
link, menu, group, or scroll controller.

## Usage

Every example on this page is fixed to the stage rather than to the page, so the component sits
where it would sit in an application without taking over the docs. In an application, provide the
handler that owns the action.

<Demo
  layout="block"
  contain
  code={`<FloatButton
  label="Create project"
  icon={<Plus />}
  onClick={() => createProject()}
/>`}
>
  <FloatButton label="Create project" icon={<Plus />} />
</Demo>

## Label

`label` is always the accessible name. `visibleLabel` also puts it on screen, which widens the
button from a circle to a pill.

## Anatomy

FloatButton renders exactly one native `<button>` with the `.cb-float-button` namespace. `label`
is its required accessible name and becomes visible only with `visibleLabel`. An icon-only button
requires an `icon`; when `visibleLabel` is true, the icon is optional. An icon is decorative to
assistive technology because the button already has a name.

## Keyboard, focus, and stacking

This is a client component because it accepts native event handlers. It keeps native button
semantics: Tab reaches it, Enter and Space activate it, and disabled prevents activation. It owns
no focus state, dismissal, portal, anchoring engine, or gesture model.

It is `position: fixed`, uses `--cb-space-5` for logical viewport offsets, and sits at the
`--cb-z-sticky` rung. It takes no raw offset, z-index, `className`, `href`, or ARIA role override.
`label` always owns its accessible name: `aria-label` and `aria-labelledby` are not accepted.
`style` is also not accepted, so raw positioning cannot replace the fixed Token contract.

## Separate contracts

`FloatButton` intentionally does not include Ant's `FloatButton.Group` or `BackTop` behaviour.
A group adds action-disclosure and keyboard/focus decisions; scroll-to-top owns scroll observation
and positioning. Both require separate public contracts when they are needed. For navigation, use
`LinkButton`, which preserves native link behaviour.

## Tokens

FloatButton reads semantic tone Tokens, `--cb-control-height-*`, `--cb-space-2`,
`--cb-space-4`, `--cb-space-5`, radius, focus, font, shadow, and `--cb-z-sticky` Tokens.

<Guidance
  do="Use one FloatButton for a primary viewport-level action such as creating a record."
