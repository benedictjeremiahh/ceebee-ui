# Mentions <span className="docs__label">Composition</span>

`Mentions` is a textarea that opens an anchored suggestion list after a trigger character. It owns text
editing and an optional mention insertion; it is not an AutoComplete, because native multiline editing
remains the primary interaction.

## Usage

<Demo layout="block" code={`<Mentions
  options={[
    { value: 'ada', label: 'Ada Lovelace' },
    { value: 'grace', label: 'Grace Hopper' },
  ]}
  defaultValue="Please review @"
/>`}>
  <Surface padding="sm"><Mentions options={[{ value: 'ada', label: 'Ada Lovelace' }, { value: 'grace', label: 'Grace Hopper' }]} defaultValue="Please review @" /></Surface>
</Demo>

Selecting Ada inserts `@ada ` by default: `value` is the stable text written into the textarea;
`label` is presentation only. Change the trigger with `trigger` and the trailing text with `separator`.
Each Mentions instance intentionally supports one trigger character. Editors that need several trigger
syntaxes, rich text tokens, or non-text mention storage are a different interaction and data contract.

## Interaction boundary

- **Role:** native textarea plus an anchored `listbox` of synchronous, injected suggestions.
- **Focus:** focus stays in the textarea. While the list is open, Up/Down changes its active option,
  Enter inserts it, and Escape dismisses the list. All other keys retain normal textarea behavior.
- **State:** `value` / `defaultValue` control text. Suggestions derive from the trigger text at the caret.
- **Dismissal:** Escape or Base UI's outside-dismiss layer closes the list; inserting an option closes it.
- **Positioning:** Base UI positions a portalled listbox below the textarea; its Positioner owns stacking.
- **Data:** `options` is synchronous caller-owned data with unique stable `value`s. Mentions never
  fetches or stores suggestions.

## Keyboard

| Key | When suggestions are open |
|---|---|
| Up / Down | Moves the active enabled option; textarea caret remains in place. |
| Enter | Inserts the active stable mention value and separator. |
| Escape | Dismisses suggestions without editing text. |
| Every other key | Uses native textarea editing, then refreshes the query. |
