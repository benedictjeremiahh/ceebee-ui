# Cascader <span className="docs__label">Composition</span>

`Cascader` selects one leaf through a sequence of anchored hierarchy columns. It is neither a flat
`Select` nor an inline `Tree`: each Right/Left move changes the active column, while one leaf path is
the only public value.

## Usage

<Demo layout="block" code={`<Cascader
  label="Location"
  options={[
    { key: 'asia', label: 'Asia', children: [
      { key: 'id', label: 'Indonesia', children: [{ key: 'jkt', label: 'Jakarta' }] },
    ] },
  ]}
  onValueChange={(path) => console.log(path)}
/>`}>
  <Surface padding="sm"><Cascader label="Location" options={[{ key: 'asia', label: 'Asia', children: [{ key: 'id', label: 'Indonesia', children: [{ key: 'jkt', label: 'Jakarta' }] }] }]} /></Surface>
</Demo>

Sibling `key` values must be unique at every hierarchy level. The selected path is the stable key
array `['asia', 'id', 'jkt']`; labels are presentation only. Repeated local keys are valid in separate
branches.

## Interaction boundary

- **Role:** a select-only combobox rendered by a native trigger button plus a named,
  Base UI-dismissable dialog containing labelled option columns.
- **Focus:** focus stays on the trigger. Up/Down changes the active enabled option in its column;
  `aria-activedescendant` exposes that option to assistive technology. Right opens a child column,
  Left returns, Enter selects an active leaf, and Escape closes.
- **State:** `value` / `defaultValue` own exactly one leaf key path. Active navigation is private.
- **Dismissal:** Escape and Base UI's outside-dismiss layer close the popup.
- **Positioning:** Base UI anchors the popup below the trigger; its Positioner owns dropdown stacking.
- **Data:** caller injects static hierarchical options. Cascader does not fetch, cache, or multi-select.

## Keyboard

| Key | Result while open |
|---|---|
| Up / Down | Moves the active enabled option in the active column. |
| Right | Opens the active option's child column. |
| Left | Returns to the preceding column. |
| Enter | Selects an active leaf. |
| Escape | Dismisses the popup without changing the selected path. |
