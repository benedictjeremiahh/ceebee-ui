# Rate <span className="docs__label">Atom</span>

A score out of a few, set by pressing one of them.

A radiogroup, not a row of buttons: exactly one of a small visible set is the definition of one, and
it buys the arrow keys and the announced position for free.

## Usage

<RateDemo />

**Pressing the current score clears it.** Nought stars and one star are different answers, and
without this there is no way back to the first.

## Read-only

Read-only is not a disabled radiogroup. There is nothing to choose, so it is an image with a label
saying what it shows — which is also what a screen reader should hear.
