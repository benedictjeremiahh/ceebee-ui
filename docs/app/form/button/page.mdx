# Button

To trigger an operation.

## When to use

A button means an operation or series of operations. Clicking it triggers the corresponding
business logic. Use one primary button for the main action, default buttons for ordinary actions,
dashed buttons for adding actions, text buttons for secondary actions, and link buttons for links.

`danger`, `ghost`, `disabled`, and `loading` refine those action states without changing the button
contract.
