# QRCode <span className="docs__label">Atom</span>

`QRCode` encodes text into a server-safe SVG image. The encoder owns QR correctness; Ceebee owns
the accessible image boundary and Token-based geometry.

## Usage

<Demo code={`<QRCode
  value="https://ceebee.dev/docs"
  label="Open Ceebee documentation"
/>`}>
  <QRCode value="https://ceebee.dev/docs" label="Open Ceebee documentation" />
</Demo>

## Boundary

QRCode renders one non-interactive `role="img"` SVG with a required accessible `label`. It stores
no scan history, opens no link, downloads no image, and does not expose the encoded value through
ARIA or data attributes. Compose a link or download control beside it when the product needs one.
The pure ESM, zero-dependency `uqr` encoder supplies the standards-compliant boolean matrix;
Ceebee deliberately does not maintain its own barcode algorithm.

## Tokens

Rendered size derives from `--cb-space-8`; padding reads `--cb-space-2`; the frame reads
`--cb-surface-raised`, `--cb-border`, `--cb-border-width`, and `--cb-radius-sm`; modules read
`--cb-fg`. The required four-module quiet zone belongs to QR encoding geometry, not visual spacing.
QRCode is synchronous and labelled as an Atom, so it intentionally has no component Skeleton.
