# Sparkline · BarMini <span className="docs__label">Widget</span>

Shape of a series, sized to sit inside a StatCard. No axis, no scale, no tooltip — the moment you
need those, reach for a charting library.

## The cases that break naive versions

- **A flat series sits on the middle line**, not on the floor. Dividing by a zero range is how a
  steady metric renders as a crash.
- **A single point is centred** rather than pinned to the left edge.
- **A zero-height bar keeps a one-pixel foot**, so "none" is visible as a bar rather than absent.
- **Non-finite values are filtered out** before anything is measured.
