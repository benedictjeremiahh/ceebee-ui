# Sparkline · BarMini <span className="docs__label">Widget</span>

Shape of a series, sized to sit inside a Statistic. Lightweight Charts owns the plotted line, area
or histogram and its hidden scales. No visible axis or tooltip: a mini chart shows direction, while
the exact value belongs beside it. Import these client components from `@ceebee/ui/client`.

## Usage

<SparklineDemo />

## The cases that break naive versions

- **A flat series stays flat**, with the scale chosen by Lightweight Charts.
- **A single point stays visible** through its marker even without a line segment.
- **A zero-height bar is absent**, not a fabricated positive value.
- **Non-finite values are filtered out** before anything is measured.
