# Calendar <span className="docs__label">Composition</span>

`Calendar` is an inline month grid. It owns a displayed month, an optional selected day, and keyboard
movement within the grid. It does not own a text field, popup, anchoring, or dismissal; use `DatePicker`
when a calendar must be attached to a date input.

## Usage

<Demo layout="block" code={`<Calendar
  defaultMonth={new Date(2026, 0, 1)}
  onValueChange={(date) => console.log(date)}
/>`}>
  <Surface padding="sm"><Calendar defaultMonth={new Date(2026, 0, 1)} /></Surface>
</Demo>

The selected date is a local calendar day: the component intentionally compares year, month, and day,
not UTC timestamps. Pass `locale` to determine the month title, weekday names, and spoken date labels.

## Interaction boundary

- **Role:** a six-week `grid` of local calendar days with optional date selection.
- **Focus:** one enabled day is a roving Tab stop. Arrow keys move by day or week; Home/End move within
  the week; Page Up/Down moves by month, or year with Shift.
- **State:** `value` / `defaultValue` own selection independently from `month` / `defaultMonth`.
- **Dismissal and positioning:** none. The Calendar stays in document flow.
- **Data:** consumers inject unavailable dates through `minDate`, `maxDate`, or `disabledDate`, and can
  inject static, noninteractive day content through `renderDay`.

## Injected day content

<CalendarDayContentDemo />

`renderDay` changes only a day button's content. Return static content such as text, an icon, or a
`span`; do not return a button, link, input, or another focusable element. It cannot replace the grid
role, focus model, date selection, or disabled behavior.

## Keyboard

| Key | Result |
|---|---|
| Arrow keys | Move focus by one day or one week, crossing month boundaries when needed. |
| Home / End | Move focus to the first / last day of the focused week. |
| Page Up / Down | Move focus and displayed month by one month; add Shift for one year. |
| Enter / Space | Select the focused enabled day. |
