# Icon

Semantic vector graphics.

## How to use

Icons come from `@ant-design/icons@6.x`. It is not a peer of this library — it arrives with the
pinned runtime, which depends on it, so it is already installed and its version is fixed with the
rest of the runtime. Import icon components from `@ant-design/icons`; they inherit the current text
colour and therefore the active Skin.

## API

Common icons accept standard SVG attributes plus `spin`, `rotate`, `twoToneColor`, `component`, and
`style`. `createFromIconfontCN` creates icon components backed by one or more iconfont resources.
