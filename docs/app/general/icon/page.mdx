# Icon

Semantic vector graphics.

## How to use

Icons come from `@ant-design/icons@6.x`, a pinned peer of this library. Import icon components from
`@ant-design/icons`; they inherit the current text colour and therefore the active Skin.

## API

Common icons accept standard SVG attributes plus `spin`, `rotate`, `twoToneColor`, `component`, and
`style`. `createFromIconfontCN` creates icon components backed by one or more iconfont resources.
