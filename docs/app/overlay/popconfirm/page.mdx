# Popconfirm <span className="docs__label">Composition</span>

`Popconfirm` asks for a lightweight decision next to its trigger. It is anchored and non-modal;
use `Modal.Confirm` when the decision must interrupt the whole viewport.

## Usage

<PopconfirmDemo />

<CodeBlock code={`<Popconfirm
  trigger={<Button variant="outline">Delete draft</Button>}
  title="Delete this draft?"
  description="This action cannot be undone."
  cancelAction={<Button variant="ghost">Keep draft</Button>}
  confirmAction={<Button tone="danger">Delete</Button>}
/>`} />

## Anatomy and boundary

The supplied native trigger anchors a Base UI Popover. The popup contains a decorative tone icon,
`Popover.Title`, optional `Popover.Description`, and an action row. Base UI owns opening, outside
dismissal, Escape, positioning, initial focus, and focus return. Each supplied action is wrapped in
`Popover.Close`, so its own click handler runs and then the popup closes. For an asynchronous action
that must remain open until success, control `open` and `onOpenChange` in the application.

<Guidance
  do="Use Popconfirm for a short, reversible-or-clearly-described choice tied to one visible action."
  dont="Use Popconfirm for long forms, multi-step decisions, or confirmation that must block the viewport."
/>

## Keyboard and dismissal

Activating the trigger opens the popup and moves focus according to Base UI's Popover contract.
`Tab` follows the supplied actions. `Escape` and action-close return focus to the trigger. Outside
interaction dismisses while leaving focus on the native outside target. The popup does not trap
focus or lock document scrolling.

## Loading

`Popconfirm.Skeleton` preserves icon, copy, and action geometry without creating a trigger, popup,
button, focus target, or portal.

## Tokens

The surface reads `--cb-surface-raised`, `--cb-border`, `--cb-shadow-md`, radius, spacing, type,
duration, and easing Tokens. Semantic emphasis reads `--cb-tone-neutral`, `--cb-tone-warning`, or
`--cb-tone-danger`. Its `Positioner`, never the popup, owns `--cb-z-popover`.
