# Drawer <span className="docs__label">Composition</span>

A modal edge panel for page navigation or a longer contextual task. It is a separate interaction
contract from Modal and Popover even though Base UI supplies the same proven focus and dismissal
foundation.

## Keyboard

`Escape` closes it. `Tab` and `Shift+Tab` stay inside while open. Focus returns to its trigger.
