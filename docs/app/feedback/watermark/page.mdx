# Watermark <span className="docs__label">Composition</span>

`Watermark` places repeated decorative marks over supplied content. It follows Ant Design's catalog
name while keeping Ceebee's semantic tone API and token-driven geometry. It ships from the client
entry because collision-safe SVG pattern IDs use React's SSR-stable `useId`; it owns no events.

## Usage

<Demo
  layout="block"
  code={`<Watermark content={['Internal', 'Ceebee']} tone="brand" density="md">
  <ProjectBrief />
</Watermark>`}

## Direction

Direction changes the tile geometry and the flow of the marks. It does not rotate or re-order the
wrapped content, which stays in its normal reading direction.

## Boundary and accessibility

Watermark renders in normal document flow. It owns no keyboard, focus, value,
dismissal, anchoring, or gesture contract. The repeated mark layer is `aria-hidden` and
`pointer-events: none`, so headings, links, buttons, and other child semantics remain the
consumer's responsibility. Do not rely on the watermark as the only channel for important meaning.

## Skeleton

`Watermark.Skeleton` — or the `WatermarkSkeleton` export, which is the same component — preserves the marked content surface while wrapped content loads. Its props are
`content`, `tone`, `density`, `direction`, and `lines`; `lines` controls the shared `Skeleton.Text`
placeholder geometry and is not content state.

## Tokens

The component reads semantic tone Tokens, foreground Tokens, font and line-height Tokens, spacing,
tile geometry, and the skin's `--cb-tint-strength` Token. The Skeleton reads the shared Skeleton
Tokens. It accepts no raw colour, angle, spacing, opacity, or sizing value. The SVG pattern paints
the complete overlay rectangle, so coverage is independent of wrapper dimensions and content length.
