# Alert <span className="docs__label">Composition</span>

An inline message about the thing a person is looking at. For something that happened somewhere
else, or that should not push the layout around, use a Toast.

## Usage

<AlertDemo />

## What it announces

`danger` and `warning` render as `role="alert"` with `aria-live="assertive"`; the quieter tones are
`role="status"` and polite. That distinction is deliberate — a success note that interrupts a screen
reader mid-sentence is not help, it is noise.

  do="Say what happened and what to do next: 'The bank declined the charge. Nothing has been billed.'"
