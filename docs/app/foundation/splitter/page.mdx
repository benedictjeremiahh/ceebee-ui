# Splitter <span className="docs__label">Composition</span>

`Splitter` divides exactly two panes with a draggable, keyboard-operable separator. It owns only the
percentage assigned to the first pane; the panes retain their own semantics and interactions.

## Usage

<Demo layout="block" code={`<Splitter defaultSize={32} minSize={20} maxSize={70}>
  <Surface padding="sm">Navigation</Surface>
  <Surface padding="sm">Content</Surface>
</Splitter>`}>
  <Splitter defaultSize={32} minSize={20} maxSize={70}>
    <Surface padding="sm"><Text>Navigation</Text></Surface>
    <Surface padding="sm"><Text>Content</Text></Surface>
  </Splitter>
</Demo>

## Anatomy and boundary

The root owns two pane wrappers and one native `role="separator"`. It has no dismissal, portal, or
anchoring contract. Pointer dragging belongs only to the separator; it captures the pointer and
calculates the first pane’s percentage from the pane space left after the fixed handle. The visual
handle stays Token-sized while a larger Token-sized pseudo-element supplies its pointer hit area.

## Keyboard

When the separator has focus, horizontal Splitters use Left/Right and vertical Splitters use Up/Down
to change by one percent. A horizontal Splitter has a vertical `aria-orientation` separator because
its panes sit left/right; a vertical Splitter has a horizontal separator. `Home` moves to `minSize`;
`End` moves to `maxSize`. `disabled` Splitters are not tabbable and ignore every key or pointer drag.

## Controlled and boundaries

Use `size` with `onSizeChange` when the surrounding layout owns the value. Otherwise use
`defaultSize`. Every supplied, keyboard-derived, and pointer-derived value is rounded to an integer
and clamped to `minSize` / `maxSize`. Non-finite `size` values use 50; non-finite `defaultSize`,
`minSize`, and `maxSize` use 50, 0, and 100. If `minSize` exceeds `maxSize`, the range resolves to
the clamped minimum.

## Tokens

Handle geometry reads `--cb-space-1`, `--cb-space-2`, or `--cb-space-3`; the separator reads
`--cb-border` and focused feedback reads `--cb-tone-brand`. Pane sizing is a percentage supplied by
the component state, not a visual Token.
