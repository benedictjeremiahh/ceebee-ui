# Typography

Basic text writing, including headings, body text, lists, and more.

## When to use

- When displaying titles or paragraph content in articles, blogs, notes, and product surfaces.
- When text needs copyable, editable, or ellipsis behavior.

## API

`Typography.Text`, `Typography.Title`, `Typography.Paragraph`, and `Typography.Link` are the exact
exported from `@ceebee/ui/client`, including copyable, editable, and ellipsis
configuration.
