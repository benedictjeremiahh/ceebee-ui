# Space <span className="docs__label">Composition</span>

`Space` arranges siblings with a spacing Token and can add a visual separator between them. It is
for sibling separation; use `Flex` when you need main-axis distribution or a general flex layout.

## Usage

<Demo layout="block" code={`<Space size="middle" align="center">
  <Text>Updated</Text>
  <Text size="sm">Just now</Text>
</Space>`}>
  <Space size="middle" align="center">
    <Surface padding="sm"><Text>Updated</Text></Surface>
    <Text size="sm">Just now</Text>
  </Space>
</Demo>

<PropsTable rows={[
  { name: 'direction', type: "'horizontal' | 'vertical'", default: "'horizontal'", description: 'Sibling axis.' },
  { name: 'size', type: '0 – 8 | small | middle | large', default: "'small'", description: 'Spacing Token; aliases map to 2, 3, and 4.' },
  { name: 'align', type: "'start' | 'center' | 'end' | 'baseline' | 'stretch'", default: "'center'", description: 'Cross-axis alignment.' },
  { name: 'wrap', type: 'boolean', default: 'false', description: 'Allows siblings to wrap.' },
  { name: 'split', type: 'ReactNode', default: '—', description: 'Visual separator inserted between siblings.' },
]} />

## Anatomy

The root is a flex container. Each child becomes one `.cb-space__item`; when `split` is present,
each separator is its own flex child between two items. `Space` has no keyboard, focus, dismissal,
anchoring, or gesture contract.

## Tokens

`size` reads `--cb-space-0` through `--cb-space-8`. The `small`, `middle`, and `large` aliases map
to spacing steps 2, 3, and 4. Compact overlap uses the `--cb-border-width` Token, while skeleton
geometry uses `--cb-control-height-md` and spacing Tokens.

## Compact

`Space.Compact` groups adjacent controls without a gap and overlaps their shared borders. It does
not own focus, keyboard, value, or selection state; those contracts stay with the child controls.

<Demo layout="block" code={`<Space.Compact>
  <button>Previous</button>
  <button>Next</button>
</Space.Compact>`}>
  <Space.Compact>
    <button type="button">Previous</button>
    <button type="button">Next</button>
  </Space.Compact>
</Demo>

## Loading

`Space.Skeleton` keeps the direction, gap, and item count while content is loading.

</Demo>
