# ProDescriptions recipe

**Ant Pro reference:** configured, request-backed, and editable `ProDescriptions` flows.

Use `Descriptions` and `Descriptions.Item` for loaded record details. Compose `Button`, `Field`,
and a separate edit form when editing is needed. Ceebee owns native label/value semantics and layout;
the application owns requests, loading decisions, edit mode, authorization, mutations, and refresh.

<CodeBlock code={`<Descriptions title="Project" columns={2} bordered>
  <Descriptions.Item label="Name">{project.name}</Descriptions.Item>
  <Descriptions.Item label="Owner">{project.ownerName}</Descriptions.Item>
  <Descriptions.Item label="Status"><Tag tone="success">Active</Tag></Descriptions.Item>
</Descriptions>
<Button onClick={() => setEditing(true)}>Edit project</Button>`} />

Non-goals: a request prop, auto-generated columns, inline mutation state, authorization checks, or
an editable descriptions component.
