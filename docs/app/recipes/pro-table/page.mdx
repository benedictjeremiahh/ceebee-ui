# ProTable recipe

**Ant Pro reference:** `ProTable`, `EditableProTable`, and `DragSortTable`.

Use presentational `Table` for already-loaded rows, with `Field`, `Input`, `Select`, and `Button`
around it for application-owned filters and actions. Ceebee owns table rendering; the application
owns queries, pagination, sorting, column visibility, optimistic edits, drag ordering, and saves.

<CodeBlock code={`<Field label="Search projects" labelHidden>
  <Input value={query} onChange={updateQuery} placeholder="Search projects" />
</Field>
<Table columns={columns} rows={projects} />
<Pagination current={page} total={total} onChange={setPage} />`} />

Non-goals: a request prop, automatic URL synchronization, editable cells, row drag-and-drop, or a
table-specific data cache.
