# ProList recipe

**Ant Pro reference:** `ProList`, card-list, search, selection, expansion, and editing patterns.

Use `Listy` for stable caller-supplied rows; compose `Input`, `Checkbox`, `Collapse`, `Card`, and
`Button` only when the application has made those state choices explicit. Ceebee owns list semantics
and row rendering; the application owns search, selection, expansion state, edits, and loading.

<CodeBlock code={`<Input value={query} onChange={updateQuery} placeholder="Search activity" />
<Listy
  items={visibleActivities}
  getKey={(activity) => activity.id}
  getGroup={(activity) => ({ key: activity.day, label: activity.day })}
  renderItem={(activity) => <ActivityRow activity={activity} />}
  stickyGroupHeadings
/>`} />

Non-goals: request fetching, virtual-scroll ownership, implicit bulk selection, card/list mode
switching, row editing, or an all-purpose `ProList` API.
