# Ceebee paints Ant's primitives before Ant does

Ant builds its stylesheet in JavaScript, so a server-rendered document carries Ant's class names and none of the rules behind them and its controls paint with the browser's native appearance until hydration. Ceebee therefore ships a pre-paint layer for Ant's primitive classes, authored from Tokens and wrapped entirely in `:where()` so it carries no specificity and every real Ant rule overrides it the instant it arrives. We reject server-extracting Ant's own rules, which was measured and is worse: Ant derives its seed from live CSS Tokens that a server cannot read, so extracted rules carry Ant's default light palette and a dark reader gets a white control where the native appearance would at least have followed `color-scheme`. We also reject a generated Ant seed for the server, which additionally needs the colour mode during rendering and so changes the ThemeProvider surface; that remains open. We accept that this layer names Ant's class and variant names, which is Substrate detail, and bound the cost by covering only the primitives a consumer can place in a first paint and by testing that every selector stays inside `:where()` and every value stays a Token.
