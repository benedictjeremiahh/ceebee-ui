# CSS is the cross-platform Token source

Ceebee authors shared Tokens and Skin cascade rules in the canonical CSS sources, then generates typed Flutter projections from their resolved values. A new Ceebee visual decision must enter that source even when only one platform consumes it initially; a value derived by a platform Substrate remains Substrate-owned instead. We reject hand-written Flutter-only Ceebee Tokens and a second neutral schema because either would create competing sources of truth, accepting that Flutter generation depends on tooling which understands the CSS cascade.
